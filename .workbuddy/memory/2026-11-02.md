## 项目：手机远程控制手机 App（代号：掌驭 PalmLink）

### 需求与决策
- 永强想做「手机控制手机」。调研结论：无体验合格的开源方案（control-droid 只是 2 秒轮询截图；droidVNC-NG/RustDesk/scrcpy 各有硬伤），决定自建。
- 关键架构决策（用户确认）：
  - 双端都做 App，但**一个 APK 装两台手机、启动选角色**（同 RustDesk 模式）
  - **GitHub Actions 云编译 APK，本地不装任何工具链**（用户明确要求不装工具）
  - **先局域网零依赖**（被控端起 HTTP 服务，二维码装 ip/port/token，扫码交换 SDP），信令抽象成 SignalingTransport 接口，后续换 CloudWs 实现接公网
  - 界面深色科技风
- 成本 0 元/月：Cloudflare Realtime TURN 免费 1TB/月 + Metered Realtime 信令免费 100 连接/10 万消息月 + GitHub Actions。
- 微信小程序路线已排除：live-player 组件个人主体不给开，需企业主体+视听许可证。
- 系统硬约束（已告知用户）：被控端每次会话必须手动同意录屏；锁屏无法注入输入；dispatchGesture 无法做连续触摸流（不能玩游戏）；iOS 不能被控。
- 技术定版（已联网核实）：Kotlin 2.2.21 + Compose BOM 2025.10.01 + AGP 8.13.2 + Gradle 8.13 + JDK 17 + `io.github.webrtc-sdk:android:150.7871.04`（备选 stream-webrtc-android 1.3.10）。min 26 / target 35 / compile 36。
